## 2024-06-04 - Inaccessible Icon Buttons on Mobile
**Learning:** There is a recurring pattern where icon buttons meant primarily for mobile (like the hamburger menu in ChatView or the close button in Sidebar) or buttons that hide their text on small screens (like the sort button in ConversationsView) completely lack accessible names (`aria-label`) and tooltips (`title`). Because Tailwind's `hidden` class uses `display: none`, hiding text on mobile removes it from the accessibility tree entirely. This makes the app highly inaccessible for screen reader users on mobile devices.
**Action:** Always verify that responsive components don't accidentally drop their accessible names when hiding text visually. Add explicit `aria-label`s to icon-only interactive elements and those that collapse to icon-only on smaller viewports.
