## 2024-03-21 - Streaming Performance in React
**Learning:** React state updates during SSE streaming can severely block the main thread if the full chat history re-renders on every chunk. In `ChatView`, an unmemoized mapping of messages combined with a complex regex string parsing function (`renderContent`) running on *all* previous chunks and the current chunk synchronously led to severe UI lock-ups.
**Action:** When handling SSE streaming in React, always memoize historical message components using `React.memo` and ensure the state update creates a shallow copy of only the modified message to avoid breaking memoization for old messages. Avoid expensive text parsing on the hot path (like running regex `match()` inside mapped text blocks) and use early returns to bypass logic when not needed.
